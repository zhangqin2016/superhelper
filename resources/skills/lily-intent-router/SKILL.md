# Intent routing

This skill is injected by the platform into every session's AGENT.md. Users
cannot disable it from Settings or per-chat skill selection.

It is not a normal user-installable skill. It is Lily's routing core: classify
the task, split mixed requests, choose the capability chain, decide the required
verification, then execute.
