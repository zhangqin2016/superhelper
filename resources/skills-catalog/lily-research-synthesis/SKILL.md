# Lily 研究事实核验

本技能用于把“查一下 / 现在最新 / 排行榜 / 价格 / 政策 / 竞品 / 资料汇总”变成可追溯、可复核的研究回答。

## 何时使用

- 用户要最新信息、近期新闻、实时价格、榜单、政策法规、标准、产品规格、公司/人物/机构现状。
- 用户要竞品调研、市场资料、资料汇总、事实核验、带来源的报告或结论。
- 用户问题里出现“最新、现在、今天、最近、排行榜、价格、政策、来源、出处、引用、核实、对比、竞品”等信号。

## 何时不用

- 用户只要创意发散、文案润色、代码实现、离线文件处理，且不依赖外部事实。
- 用户明确要求“不联网”或只使用给定材料；此时只能基于材料回答，并说明没有做外部核验。
- 纯视觉创意方向优先用 `lily-creative-director`；只有涉及真实资料、案例、趋势或竞品时再叠加本技能。

## 流程

1. **明确问题和时效性**：判断哪些事实会变化，必要时说明检索日期和地域口径。
2. **必须联网检索**：不要凭记忆回答可变事实。使用当前可用搜索后端；国内搜索后端可替换，搜索策略不能绑定某一家服务。
3. **多来源交叉验证**：重要结论至少找两个独立来源；优先官方、监管、公司公告、原始数据、权威媒体或一手文档。
4. **打开并阅读来源**：不要只看搜索摘要。能打开原文就读原文；不能打开则降级使用其他可读来源。
5. **判断新旧和冲突**：记录发布日期、更新日期、数据周期。来源冲突时说明冲突点，优先更新、更直接、更权威的来源。
6. **区分事实和推断**：事实给来源；推断写明依据；不确定时说不确定，不补造细节。
7. **按用户目标合成**：不是堆链接，而是提炼结论、证据、限制和下一步。

## 质量红线

- 最新、价格、政策、排行、竞品信息未联网，不算完成。
- 只引用一个来源就下强结论，不算完成，除非该来源是唯一官方原始来源。
- 只给链接列表、没有综合判断，不算完成。
- 隐去日期、地区、版本、适用范围导致误导，不算完成。
- 把广告稿、论坛传闻、二手转载当成已核验事实，不算完成。

## 输出要求

- 用用户语言回答，先给结论，再给依据。
- 每个关键事实附来源名称和链接；无法链接时说明来源名称、日期和获取方式。
- 对时效性敏感的回答注明“检索/核验日期”。
- 对政策、价格、法规、医疗、金融等高风险信息，加上适用范围和建议用户以官方原文为准。
- 资料汇总类输出要包含：核心结论、来源表、冲突/不确定点、可继续追查的问题。

## 和 lily-creative-director 的关系

- `lily-creative-director` 负责创意方向、画面风格、构图和媒介表达。
- 本技能负责事实底座：真实案例、竞品资料、行业趋势、政策限制、产品参数、品牌背景。
- 做“基于真实竞品/趋势/政策的创意方案”时，先用本技能查证事实，再用 `lily-creative-director` 转成创意方向。
