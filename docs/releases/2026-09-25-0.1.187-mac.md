# Mac 0.1.187 release

## Scope

Mac ARM64 and Intel, aligned with the observed Windows stable version 0.1.187.
Source commit: `a8a95b2b`. Includes scheduler recovery, process-job wake and
scope ownership, tool-result ownership, mobile message ordering and desktop
dictation credential fixes. Mobile web/server changes need their own deployment.
No Windows, server, website or separate skill catalog publication in this task.

## Verification

- Online Mac dependency preflight and both architecture builds passed.
- Both packaged ASARs match all 1129 source files in the isolated release snapshot.
- Full isolated suite: **1126/1126 passed in 892 seconds**.
- Both DMG/ZIP application trees match; deep signature verification and packaged
  Python matplotlib chart rendering passed for both architectures.
- Builds remain ad-hoc signed, not Apple Developer ID signed/notarized.
  A complete installed GUI/model-turn or auto-update/restart cycle has not been
  verified. The previous release's isolated GUI probe was blocked in macOS
  keychain access; this release does not claim that limitation has been resolved.
