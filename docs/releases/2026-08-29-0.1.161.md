## Limits

- macOS signing is **ad hoc**, not Apple Developer ID signing/notarization. The
  release machine has no valid Developer ID identity or notarization credentials.
  Passing local signature checks does not guarantee Gatekeeper acceptance or
  automatic installation through Squirrel.Mac.
- No real paid-provider conversation, clean-machine customer installation, or
  physical Intel Mac installation was exercised as part of this release.
- Existing dependency audit findings were not automatically upgraded during the
  release; passing tests do not establish that the dependency tree is risk-free.
- The local upload tool required a temporary loopback-only IPv4 transport for
  Qiniu because its direct IPv6 connections failed. TLS verification stayed on;
  no global network settings were changed.
