## Changes and use

- Task summaries distinguish delivery from verified completion with localized
  labels. A successful final test can count as evidence, including the exact
  supported exit-report wrapper; failed, missing or stale evidence cannot.
- Original requirements and structured output paths inform acceptance. Eligible
  incomplete execution can continue once through the existing durable recovery
  path, preserving permission boundaries and completed work. No new UI action
  is required; ordinary natural-language tasks use this behavior.
- Hidden Electron regression tests disable background timer/renderer throttling.
  This changes the test runner, not product window settings.
