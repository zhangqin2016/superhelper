# Lily Workbench 0.1.166 Release

## Status

**Published.** Source push, both Mac installers, auto-update ZIPs, service release
rows, signed manifest and architecture feeds are complete. Public pointers match
the local release files exactly after a successful CDN refresh.
Targets: macOS arm64 and x64. Packaged source commit: **ce12b9a6**.

## Changes and use

- Task summaries distinguish delivery from verified completion with localized
  labels. A successful final test can count as evidence, including the exact
  supported exit-report wrapper; failed, missing or stale evidence cannot.
- Original requirements and structured output paths inform acceptance. Eligible
  incomplete execution can continue once through the existing durable recovery
  path, preserving permission boundaries and completed work. No new UI action
  is required; ordinary natural-language tasks use this behavior.
- Hidden Electron regression tests disable background timer/renderer throttling.
  This changes the test runner, not product window settings.

  was performed. It does not establish Gatekeeper or clean-machine install success.
- No logged-in IM acceptance or fresh real-model acceptance of the new recovery
  loop was performed for these packages. Empty-profile startup is a narrower check.
- Earlier real-client creation and repair tests, the later localized-summary
  check, and current automated tests are separate evidence. The earlier receipt
  and label defects are fixed in source; fresh full-client model acceptance remains
