## Verification

- Capability registry: 84 gates and 84 documentation anchors passed.
- Full suite: 925/932 passed in 523 seconds. Seven document/runtime tests failed
  because the concurrent build recreated the Python environment and its ONNX
  dependency download timed out. After restoring the complete runtime, all seven
  failed commands were rerun and passed. This is a full run plus targeted reruns,
  not a single uninterrupted 932/932 run.
- Online dependency preflight, both architecture package checks and both mounted
  DMG checks passed. App and OpenCode ad-hoc signatures verify successfully.
- Both packaged ASARs match 914 current source/package files, including untracked
  new modules. OpenCode reports 1.18.29 for both architectures.
- Both packaged Python interpreters successfully import PIL, cv2, numpy,
  openpyxl, docx, pypdfium2 and onnxruntime.
- No Apple Developer ID signing identity is available; packages are not notarized.
- Full arm64 startup acceptance remains incomplete: an isolated temporary profile
  blocked in macOS `SecItemCopyMatching` / Keychain content decryption before its
  UI could be inspected. No security controls were disabled. The test process
  was terminated and no required test/build process remains running.
- Intel binaries were exercised under Rosetta, not on physical Intel hardware;
  the engine emits a Bun AVX warning under that environment.
