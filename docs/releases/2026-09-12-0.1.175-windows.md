# Lily Workbench 0.1.175 Windows Release

Published Windows x64 from frozen commit `6d807713`, based on upstream
`47c7feed`.

## Changes

- Preserve bounded long-task continuation budgets, source identity, progress
  receipts and pause notices across retries and application restarts.
- Refuse incomplete model streams as successful completion while retaining
  partial streamed text for diagnosis.
- Add fail-soft model discovery for a custom OpenAI- or Anthropic-compatible
  endpoint while keeping manual model entry available.
- Add opt-in image generation through the active Codex Relay model. Existing
  media providers retain precedence and unchanged defaults.
- Bundled OpenCode CLI and SDK remain 1.18.29.
