# Lily Workbench 0.1.162 Release

## Scope

- Source branch: `feat/opencode-engine` on GitHub.
- Application build commit: `79db5a4` (rebased after `1eebcf9`).
- Targets: macOS arm64 and x64. Windows and the production API/web images were not rebuilt.
- Change: packaged Lily now discovers installed system, package-manager, user, and
  login-shell executable directories without inheriting unrelated host secrets or
  accepting unsafe relative search paths.

## Verification

- Full local suite: **659/659 passed** in 314 seconds.
- Post-rebase focused tests passed for executable discovery, packaged spawn
  environment, OpenCode runtime ownership, Windows path portability, context
  window guard, and bundled usage accounting.
- Online Mac runtime-pack preflight passed. Twenty production artifacts remain
  verified online but pending local lock entries, so offline strict preflight
  remains blocked as recorded by the release gate.
- Both applications passed base-runtime, OpenCode engine, macOS junk, app bundle
  signature, mounted DMG, and Electron framework checks.
- The public signed manifest verifies with the application public key. Both public
  auto-update feeds resolve to `0.1.162` and their SHA-512 values match the local ZIPs.
- Both production release APIs return `0.1.162` with the expected platform, URL,
  SHA-256, and size. All four public artifacts return HTTP 200 with matching sizes.

## Operational Notes

- Direct Qiniu upload failed over this release machine's broken IPv6 route before
  any pointer changed. The already verified artifacts were then uploaded through a
  temporary loopback-only, allowlisted IPv4 TCP tunnel. TLS remained end-to-end;
  the tunnel was stopped after publication.
- CDN refresh returned code 200 for the signed manifest and both update feeds.
- macOS signing remains ad hoc because this machine has no valid Apple Developer ID
  or notarization credentials. This is the same known limitation as 0.1.161.
- No clean-machine customer installation or physical Intel Mac launch was performed.
