# 0.1.189 release (mac + windows)

## Scope

macOS ARM64 + Intel and Windows x64, version 0.1.189. Source: `3eddcdc9` plus
this version bump.

Includes:
- The official China legal counsel agent reads a served corpus: the governing
  law first, then the article inside it (`lily_legal_search` with `laws`,
  `lily_legal_article` for full text). Measured on 25 plain-language questions:
  21/25 without a law hint, 24/25 with one (the V2 service alone: 7–8/25).
  While the service is unreachable an installed local pack answers
  (`local-fallback`); refusals are never routed around; the local pack is
  retired only after the service has answered.
- A context window is known (configured, learned, catalogued) or honestly
  unknown; the context-window guard acts only past the real limit, measured
  with reported usage; an overflow is answered by compaction and keeps the
  conversation.
- A new question in a long session reaches the model whole.
- Lily's `node` shim gives yargs/commander Node's argv layout; a continuation
  round that changed files earns a look at its relaunched job's outcome, and a
  paused chain states the job's real result.
- A provider 429 whose message is only "Error" is classified by status.

The served legal search needs the API route and the retrieval gateway deployed
(`deploy/legal-kb/`); until then the fallback above applies. Ordinary chat never
depends on it.

## Verification

- All three installers built; `verify-mac-pack` passed for both Mac builds.
- **Windows was not verified on Windows.** `verify-win-pack`'s runtime smoke
  step must run on a Windows host and this release was built on macOS; the
  step failed as designed and the user chose to publish Windows unverified, as
  with 0.1.188. The installer is signed via signtool; a real Windows install
  and launch has not been run.
- Release preflight passed with online runtime-pack verification.
- Public checks after publication (HTTP 200): `app/updates/latest.json` and the
  three stable auto-update feeds announce 0.1.189; the releases API returns
  0.1.189 for all three platforms with the artifact SHA256 and size below; the
  installers and auto-update packages download at the expected sizes.

## Skill-catalog false conflict

`publish-local-catalog-server.mjs` refused 12 packs as "changed under a
published version" although no file in them changed: `build-skill-pack.mjs`
pins file entries to 2000-01-01, but JSZip writes the folder entries it creates
(`scripts/`) with the build time, so the same content zips to a different
SHA256 at a different time, and the conflict check compares archive hashes.
The published `anthropics-docx@1.0.3` and a fresh build unzip to identical
files. Fixed separately: deterministic folder entries, and a conflict means
different contents.
