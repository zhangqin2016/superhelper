this version bump.

  gets `NO_PLATFORM_PACKAGE` from the static manifest and uses the releases API,

## Upload

The uplink ran at 0.2–0.6 MB/s: the versioned installer took 52 minutes. The
auto-update package is the same file; `release-admin.mjs` now skips an object
that already holds the file's Qiniu etag and copies a second key inside Qiniu
(`qshell copy … -k <dest>`), falling back to the upload whenever the result
cannot be proved. The first attempt passed the destination positionally, qshell
copied the file onto itself, the etag check caught it and fell back; the run was
stopped before any release row or pointer was written, the copy was made
correctly by hand (etags verified), and the re-run skipped both uploads.
