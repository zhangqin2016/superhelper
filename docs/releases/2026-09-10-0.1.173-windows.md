# Lily Workbench 0.1.173 Windows Release

Published Windows x64 from frozen commit `00118ea0`, based on upstream
`daa938a9`.

## Changes

- Probe and persist vision capability for custom BYOK models, with a manual
  override when probing is disabled or a provider false-negatives. Unknown
  capability keeps the existing image-translation bridge.
- Add an opt-in OpenAI-compatible image-generation provider supporting base64
  and URL responses, plus one bounded retry when `response_format` is rejected.
- Remove the output-limit field from actual OpenCode execution when the endpoint
  explicitly taught the probe that it rejects that field.
- Raise the runtime identity active-skill authorization cap from 64 to 256 and
  report a specific, actionable error if that real scope is exceeded.
- Keep every existing model, tool, context and media-provider path unchanged by
  default. Bundled OpenCode CLI and SDK remain 1.18.29.
