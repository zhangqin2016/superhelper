## What is inside

- Windows runtime bundle 950 MB: Python 3.12, uv 0.6.14, the document venv.
- **matplotlib 3.11.2 is present in the venv** — the chart renderer added this
  session actually shipped, verified inside `win-unpacked`.
- All five new main-process modules are in `app.asar`, and the three changed
  Python helpers are in unpacked resources with their new functions present.
- **No LibreOffice.** The manifest records `"libreoffice": null` by design:
  Windows installs it on demand as the recommended `libreoffice` runtime pack
  (450-800 MB download). Office conversion, document rendering, spreadsheet
  recalculation and visual verification all need that pack installed, so the
  conversion and pagination repairs cannot be exercised on a Windows machine
  until it is.
