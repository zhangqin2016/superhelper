# Lily Workbench 0.1.168 Windows Release

Published Windows x64 from commit `2aaa2bcf`, including upstream workspace
collaboration commit `0883cd54` and visible-message read acknowledgements.

## Changes

- Workspace collaboration entry reuses task preparation, receipt, delivery,
  local application and rollback. Existing account and rollout checks remain.
- Task handoff focuses the created form after the chooser closes without waiting
  for an animation frame; existing navigation/account ownership checks remain.
- Windows Electron test profile locks no longer mask behavioral exit codes.
  Locked temporary profiles are reported and retained; unexpected errors fail.
- The previous database WAL compaction protection remains included.

## Verification

- Windows workspace-entry, dual-client task UI, cached-transfer UI, focus UI and
  visible-read UI tests passed. Initial entry focus failure was fixed before
  packaging. Profile cleanup locks were reported without hiding assertion failures.
- Project-source, remote-task-transfer, WAL compaction, architecture and Windows
  installer guards passed. Release runtime preflight passed.
- Packaged workspace entry, handoff and WAL compaction source match local source
  byte for byte. Version 0.1.168, OpenCode CLI and SDK 1.18.21 verified.
- Windows payload verification passed: 13,477 files, approximately 1575 MB

- Installer, auto-update installer and blockmap return HTTP 200 with exact sizes.
  Public signed manifest and Windows stable feed match local files byte for byte.
