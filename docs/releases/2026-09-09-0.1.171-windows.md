# Lily Workbench 0.1.171 Windows Release

Published Windows x64 from frozen commit `d02905b4`, based on upstream
`2442d6ee`.

## Changes

- Upgrade the bundled OpenCode CLI and SDK from 1.18.21 to 1.18.29.
- Learn OpenAI-compatible request parameter changes from explicit server errors,
  with bounded adaptation and unchanged baseline behavior for unrelated failures.
- Support models whose verified tool-call surface is the Responses API, while
  retaining the compatible SDK route for every other preset.
- Accept server-delivered request-shape hints without hard-coding providers or
  model names. Unknown and malformed hints retain the existing request shape.
- Refuse new secrets when OS secure storage is unavailable instead of silently
  storing Base64 plaintext. Existing records remain readable and reusable.
