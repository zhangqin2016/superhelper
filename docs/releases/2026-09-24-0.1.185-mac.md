# Mac 0.1.185 release

## Scope

Mac ARM64 and Intel, source `5af66cbaa20b92da3476b0f63d27afcf288bfe2e`.
Includes desktop support for phone prompt replies, progress, new sessions and
result file transfer. No server, website, Windows or separate skill catalog
publication. Related phone web/server changes require their own deployment;
this release does not claim a new multi-device production acceptance.
OpenCode remains 1.18.30. Version files advanced from 0.1.184.

## Verification

- Online Mac dependency preflight and both architecture builds passed.
- DMG and update ZIP application trees match on both architectures. Packaged
  resources match source, deep signatures verify, and packaged Python rendered
  matplotlib charts on both.
- Both ASARs match 1125 source/package files and engines report 1.18.30.
- Initial full suite: 1122/1123 passed in 1076 seconds; it hit the runner's 180-second deadline on
  `test-document-translator.mjs`. Two standalone unchanged runs passed with
  runtime-backed assertions. No product or test timeout was changed. Full-suite
  subsequent verification results are recorded below.
- The workspace rerun passed 1122/1123 in 916 seconds, but detected an unrelated
  concurrent untracked `scheduled-task-self-heal.js` change in the turn-failure
  shape test. That file is absent from the release. Verification therefore moved
  to an isolated archive of the release commit, with Node 22 and the same installed
  dependencies. All 1124 packaged source files match that archive on both architectures.
- Final isolated full suite: **1123/1123 passed in 835 seconds**. The isolated
  environment required the existing ignored stock-app fixture and vendored
  Playwright dependencies; both were supplied before the final full run. No
  product code or test assertions were changed. Concurrent workspace changes
  made after packaging are not included in this release.
- GUI acceptance is incomplete: both isolated checks timed out on CDP
  `Runtime.evaluate`. A native sample of the second run shows main-thread
  `SecItemCopyMatching` / keychain content access. No system authorization or
  encryption bypass applied; test children were cleaned up. No authenticated
  model turn or installed auto-update/restart cycle was verified.
- Signatures are ad-hoc, not Apple Developer ID notarization. Intel execution
  used Rosetta and emitted Bun's AVX warning; physical Intel was not tested.
