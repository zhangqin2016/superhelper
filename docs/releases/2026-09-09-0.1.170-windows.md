# Lily Workbench 0.1.170 Windows Release

Published Windows x64 from frozen commit `028221b4`, based on upstream `a909e6f2`.

## Changes

- Prevent recursive task recovery and preserve committed interruption history.
- Preserve original task intent through durable request references and coordinate
  recovery ownership across restart and lease resumption.
- Resume repeated-prose observation after closed code fences without restricting
  productive work, code, unknown input, model context or available tools.
- Include external packaged-resource resolution for job observation consumers.
- Retain existing database WAL compaction protection and model configuration.
