# Lily Workbench 0.1.167 Mac Release

Published for macOS arm64 and x64 from source commit
`1139ffd56daee6c50ff349bec1b887ca4631771b`.

- arm64 release row: `rel_vy3kkhyuf5jtau`.
- x64 release row: `rel_yi36a2yz2gil23`.

  `lanrensoft` bucket, served through `https://qny.lanrensoft.cn`.

- Qiniu CDN refresh returned code 200 / success.
- Windows was independently published as 0.1.167 before the Mac promotion.
  The existing signed Windows entry was preserved; this release did not build

## Verification

- Capability gate: 273 tests, exit 0. The focused message database compaction
  regression also passed separately.
- Online runtime-pack preflight passed for both Mac targets. Twenty artifacts
  were present in production without local lock entries; this does not assert
  that the offline lock is complete.
- Both app bundles passed code-signature checks and mounted-DMG checks.
- Packaged source and package identity/dependencies matched the current source
  across 888 tracked entries for each architecture. Build-only package metadata
  is intentionally stripped by electron-builder.
- Both bundled OpenCode binaries returned version 1.18.21. Intel execution was
  under Rosetta, which emitted a Bun AVX warning, not physical Intel acceptance.
- Both bundled Python runtimes imported Pillow, OpenCV, NumPy, openpyxl,
  python-docx and pypdfium2 successfully; Intel ran under Rosetta.
- All four public object lengths and Qiniu content hashes matched local files.
- Plain public URLs, without cache-busting parameters, returned a valid signed
  0.1.167 manifest and feeds matching local files byte for byte.
- Both public release APIs matched the DMG URLs, SHA-256 values and lengths.
- ZIP SHA-512 values matched the stable feeds. Actual ranged downloads from
  all four public artifact URLs returned the expected first byte.
- The Windows public URL, SHA-256 and length matched its preserved pre-existing
  signed-manifest entry.

## Acceptance Boundaries

No Apple Developer ID identity was available; these packages use ad-hoc
signatures and were not notarized. Local signature validation is not Gatekeeper
or clean-machine installation acceptance.

The isolated packaged-client startup test did not complete. A native sample
showed the main thread waiting in macOS Keychain `SecItemCopyMatching` and
decryption calls. The test process was stopped; encryption and Keychain access
controls were not disabled. Full startup, logged-in model execution and physical
Intel Mac acceptance remain unverified for these packages.
