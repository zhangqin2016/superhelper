# Mac 0.1.183 release

## Scope

Mac ARM64 and Intel, source `31a5f4f7`. Version advanced from the already
published 0.1.182 to preserve immutable artifacts. OpenCode remains 1.18.30.
No Windows, server or separate skill catalog publication.

Includes the current turn-completion/announced-continuation fixes and the merged
collaboration task workflow. This release does not claim new end-to-end server
or multi-device acceptance.

## Verification

- Both architectures built successfully with `npm run dist:mac`.
- Online Mac dependency release preflight passed.
- Packaged foreground launcher actually executed its wrapped command from
  inside app.asar for both architectures; deep signatures verified.
- Read-only DMG application trees equal the auto-update ZIP trees; ASARs match
  the built applications and tracked resources match source.
- Both packaged Python runtimes imported the Office/PDF/OCR/image libraries
  and rendered a matplotlib chart. Packaged job-observation checks passed.
- Initial full suite: 1083/1084 passed in 1012 seconds. Exit-confirmation test
  hit its four-second startup deadline instead of observing the fixture exit.
  Independent runs reproduced the timeout and also passed unchanged. Only the
  test's deadline was changed to the existing production default (20 seconds);
  all exit, ownership, surviving-writer and termination assertions remain.
  Five consecutive actual-process repetitions passed. Product timeouts and
  model parameters were not changed. Fresh full suite: 1084/1084 passed in
  907 seconds. `git diff --check` passed.
- Packaged source comparison passed for 1089 source/package files on both
  architectures, and both bundled engines reported 1.18.30.
- GUI startup acceptance remains incomplete: the isolated ARM64 process blocked
  in macOS `SecItemCopyMatching` / keychain content access (native sample saved),
  and the renderer-open probe timed out. User was asked to handle the system
  prompt; no response was received before completion. The isolated process was
  terminated by the probe cleanup. No keychain permission or encryption bypass
  was applied. This release does not claim GUI or authenticated model-turn
  acceptance. Sample: `/tmp/lily-mac-0183-startup-sample.txt`.
- Intel execution checks use Rosetta, not physical Intel hardware. Application
  signatures are ad-hoc, not Apple Developer ID notarization.
