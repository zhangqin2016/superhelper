# Mac 0.1.180

## Scope

- Source: `19b33aca`, branch `feat/opencode-engine`.
- Mac only: darwin-arm64 and darwin-x64. No server deployment or skill registry publication.
- Changes include large-history/session switching performance, long-task recovery ownership, recorded-process signal protection and renderer recovery.
- Windows baseline: 0.1.179. Preserve its server record, stable feed and shared static manifest unchanged.
- The ordinary one-click publication was blocked before execution because replacing global `app/updates/latest.json` would remove the Windows fallback entry. The safer publication uses existing artifact/server primitives with a hard `darwin-arm64`/`darwin-x64` path allow-list: Mac artifacts, Mac release records and Mac stable feeds only. The shared manifest is not uploaded. Clients select the newer service release via `preferNewerUpdate`; the website also uses the per-platform release API.

## Local Verification

- Both architectures rebuilt using the repository Mac distribution scripts.
- Online Mac runtime-pack preflight passed. Some production artifacts still lack local lock entries; online presence was checked, not full local-lock coverage.
- Both packaged ASARs matched 1,030 current source/package entries; both bundled OpenCode binaries returned 1.18.30.
- Packaged Python document/image imports and job-observation modules passed on both architectures.
- Final DMG/ZIP application trees matched byte-for-byte; signatures and tracked external resources were verified. Both read-only DMGs rendered a chart using bundled matplotlib 3.11.2.
- The first Intel artifact comparison failed because a concurrent packaged-Python probe wrote bytecode during packaging. The Intel app was rebuilt/re-signed, ZIP and DMG recreated sequentially, and the full comparison passed. Failed candidates were not published.
- ARM64 application launched with an isolated profile and rendered the nonblank home screen. Startup initially waited on macOS Keychain; no Keychain, TLS or application security bypass was used. Screenshot: `/tmp/lily-mac-0180-home.png`.
- Full regression: **1020/1020 passed**, 851 seconds. Log: `/tmp/lily-mac-0180-tests.log`.
- Online publication evidence is recorded below.

## Acceptance Limits

- Ad-hoc signatures, no Apple Developer ID notarization.
- Intel execution was tested through Rosetta, not on a physical Intel Mac; the engine reports an AVX warning under Rosetta.
- No claim of installed-client update/restart, customer-profile migration, every provider, or every end-to-end task being manually accepted.
