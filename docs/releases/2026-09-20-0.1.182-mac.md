# Mac 0.1.182 release

## Scope

Mac ARM64 and Intel only, based on `9b78363d` (runtime changes `c5224027`).
OpenCode stays at 1.18.30. No Windows, server, model configuration or separate
skill catalog publication. Existing untracked files are preserved.

## Local verification

- `npm run dist:mac` passed for both architectures.
- Online Mac dependency release preflight passed.
- Full suite: 1023/1023 passed in 763 seconds.
- Both ASARs match 1034 current source/package files; packaged engine starts.
- Read-only DMG verification: application trees match their auto-update ZIPs,
  tracked resources match source, strict deep signature verification passes,
  packaged matplotlib renders a chart for both architectures.
- Packaged Python imports for Office, PDF, OCR and image dependencies passed;
  packaged job-observation modules passed for both architectures. Bytecode
  writes were disabled for this probe to preserve signed files.
- Native ARM64 startup showed the office onboarding dialog and usable chat
  home; dismissing onboarding worked. Initial concurrent CDP probes timed out,
  with one load fallback and recovery-link error recorded. A serial probe after
  the suite completed passed and captured `/tmp/lily-mac-0182-home.png`.
  The isolated unsigned-in profile had no server model configuration: this is
  startup/rendering acceptance, not an authenticated model conversation test.
- Intel checks ran through Rosetta, not a physical Intel Mac. No installed
  auto-update/restart cycle was performed.
- Application signatures are ad-hoc, not Developer ID notarization.
