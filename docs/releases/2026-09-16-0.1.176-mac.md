## Verification

- Full regression rerun: **972/972 passed in 493s**. Tests requiring optional
  external infrastructure retain their own skip conditions; this is not a claim
  that every optional live integration ran.
- The initial run was 971/972. `test-opencode-runtime-ownership.mjs` failed
  because its isolated identity mock omitted the new pre-compaction grant
  export. Added the mock with an assertion that identity is disabled in this
  fixture; no product behavior or test assertion was weakened. All 15 ownership
  cases and the subsequent full suite passed.
- Explicit native 1.18.29 -> 1.18.30 engine upgrade passed using one isolated
  database: preserved session/message IDs and original context, streaming,
  no duplicate turns, Lily prompt, cancellation followed by new work, and
  OpenAI Responses. This uses a scripted localhost model, not model-quality
  or production-provider acceptance.
- Online Mac runtime-pack release preflight passed. Base Python requirements
  and builder were unchanged, so the existing runtime was reused after strict
  smoke checks. Intel's first OCR import timed out; a diagnostic import passed
  and the standard strict check then passed. Both packaged runtimes imported
  Office/PDF/OCR libraries plus Pillow/OpenCV/NumPy successfully.
- Both engines and SDK match 1.18.30. Both ASARs match **980** source/package
  entries. Actual packaged job-observation consumers executed successfully.
- Both app bundles passed deep/strict ad-hoc signature verification. Both DMGs
  mounted with the Electron framework present and no macOS metadata junk.
- Actual arm64 packaged app started with an isolated temporary profile and
  rendered the workbench and first-run office-skills dialog. Screenshot:
  `/tmp/lily-mac-0176-home.png`. Test process closed normally; no Keychain or
  encryption bypass was used.
