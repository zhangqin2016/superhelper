# Lily Workbench 0.1.172 Windows Release

Published Windows x64 from frozen commit `9115a243`, including upstream model
secret-storage correction `c1abe848`.

## Changes

- Upgrade the bundled OpenCode CLI and SDK from 1.18.21 to 1.18.29.
- Learn OpenAI-compatible request parameter changes only from explicit server
  errors, with bounded adaptation and unchanged behavior for unrelated failures.
- Support models whose verified tool-call surface is the Responses API, while
  retaining the compatible SDK route for every other preset.
- Accept server-delivered request-shape hints without hard-coded provider or model
  names. Unknown and malformed hints retain the existing strong request shape.
- Refuse new or changed secrets when OS secure storage is unavailable instead of
  silently storing Base64 plaintext.
- Re-saving an unchanged existing API key now reuses its protected record, so
  self-heal re-probes and ordinary edits do not require secure storage again.
