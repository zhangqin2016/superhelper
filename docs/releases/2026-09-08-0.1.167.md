# Lily Workbench 0.1.167 Windows Release

Published Windows x64 from commit `1139ffd5` on `feat/opencode-engine`.

## Change

Database compaction refuses to replace the main database when a source WAL
exists, checked before copying and before swapping. A WAL belongs to its
original page layout and must not be replayed onto a VACUUM copy. Refusal keeps
the original store available without deleting committed WAL records.

This prevents the identified compaction failure; it does not automatically
repair pre-existing database/WAL mismatches. The affected local installation
was backed up and recovered separately before this release.
