## Release outcome

During the final documentation push, GitHub gained parallel commit `2aaa2bcf`
(Windows task handoff focus / Electron test cleanup). It is preserved in the
subsequent source merge, not retroactively included in the already published
0.1.168 Mac artifacts built from `0883cd54`. Artifact hashes above remain immutable.
Merge-time Electron validation reproduced focus loss on Mac after that parallel
change. The source merge also guards delayed panel/back focus from overwriting
an already focused task input, preserving Windows' animation-frame-independent
handoff. The controlled delayed-frame regression failed before the guard and
passed afterward; 21 remote-task suites, visible-read, two-pane, right-panel and
architecture checks passed on the merged source. These later focus changes are
source-only, not a claim that the published Mac bytes were rebuilt.

API deployed and healthy; ordinary-account collaboration defaults enabled; Mac
0.1.168 published and public downloads/updates verified; source pushed to both
existing remotes. Full installed-client, physical dual-device and Apple
notarization acceptance remain outside the verified results listed above.
