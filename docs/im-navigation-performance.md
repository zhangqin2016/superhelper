# IM 切换实现与验证

点击会话立即更新选中行和标题，清除旧会话消息、附件与搜索状态，草稿绑定到目标会话。通过现有 open IPC 的严格布尔 cached 参数请求本地预览。主进程直接读取账户隔离的 SQLite，不等待网络同步队列；撤权、缺失或待 hydration 的记录拒绝预览，继续原有网络读取。

远端读取在渲染器按最新导航代次排队，过期未开始任务跳过。正在执行的请求仍完成原有服务端校验与持久化，返回结果受窗口和导航代次保护。网络写入继续使用原有同步 lane；不为了速度取消权限保护。

新会话导航不再走同会话旧历史的批量刷新路径，避免首屏重复渲染；后台刷新继续保留撤回/可见性同步。缓存窗口最多 200 条并保留独立待发送尾部，最终使用远端页合并。

验证：缓存 eligibility 与最新请求队列单测、IPC、客户端 service、scope 撤权、history 合并及真实 Electron 导航/引用测试。模拟远端悬而未决时，本地正文已经可见。未声称生产端到端毫秒指标；首次无缓存的正文仍等待网络，但窗口选择立即响应。主进程和 preload 已变更，需要完整重启开发客户端；安装包需重新构建。
