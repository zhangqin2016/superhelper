# Windows 0.1.180 release

## Scope

Windows x64 only. Product/version commit: `19b33aca`; Windows test follow-up:
`8e1dec41`. Includes local recovery fix `88d16803` and upstream renderer/process
protection changes through `aac4d165`. No model server deployment, macOS build,
or local skill/app catalog publication.

Long-task changes require authoritative idle before recovering a completed
assistant step as final output; stale asynchronous recovery cannot terminate
renewed work; confirmed busy engines retain progress/health guards instead of
being failed solely by the transient transport grace period. User waits and
explicit administrator deadlines retain their existing semantics.
