# Windows 0.1.181 release

## Scope

Windows x64 only. No macOS, GPU/server deployment, model/context reduction or
skill/app catalog publication. OpenCode remains pinned to 1.18.30.

Normal completion and recovery share execution ownership checks across async
status/history/replay reads. Valid sparse engine status maps mean idle; failed
queries remain unknown. Newest assistant errors/tool steps cannot become success
because an older assistant had text. History joins use explicit parent identity
for empty aborted/failed turns. Markdown/CSV delivery no longer requires Office
page rendering or substitutes a misleading missing-Office-file answer.

## Native Acceptance

Actual Windows desktop, isolated 2 GiB history profile and real configured model:

- Spreadsheet read and computed table: 11 seconds, automatic idle.
- Report generation: 72 seconds / 14 steps exposed the text-delivery defect.
- Fixed report generation: 51 seconds / 13 steps, original source read, Markdown
  and CSV generated and read back, final table/file links intact, automatic idle.
- Stop became interrupted. Real network outage was an explicit failure, not
  successful completion. Manual retry recovered in 19 seconds / 7 steps.
- Reopened history retained the failed attempt and successful result without
  the extra empty failure copies visible before the history fix.
- Loaded the 4103-message synthetic conversation through the desktop sidebar.
- Packaged 0.1.181 executable reopened that history and the report conversation;
  a real CSV read completed in 10 seconds with correct totals and automatic idle.
  Packaged startup logged one 6253ms main-loop lag under this stress profile;
  no persistent hang was observed. This is not zero-latency startup acceptance.

Text content certification remains unverified in the independent delivery gate
and is labelled accordingly. Minute-scale native runs and virtual-clock tests
do not certify hours-long customer tasks or every skill/provider. No customer
history was deleted. The production customer's exact log is still needed to
prove their particular cause.
