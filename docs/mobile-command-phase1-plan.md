# 移动端控制 - 阶段 1 实施计划

## 核心思路：顶级、越来越聪明

**原则**：
1. **从最简单开始**：先实现一个最小可用版本（MVP）
2. **每步都可验证**：每个阶段都有明确的测试标准
3. **渐进式增强**：在稳定基础上增加功能
4. **失败安全**：新功能失败不影响现有功能

---

## 阶段划分

### 阶段 1：基础配对与消息通道（当前）
**目标**：移动端可以发送文本消息到桌面端 Lily 会话

**交付物**：
- ✅ 数据库迁移（配对表）
- ✅ 服务器配对 API
- ✅ 移动端扫码配对
- ✅ 移动端发送消息到桌面

**验证标准**：
- 移动端可以扫描桌面的 QR 码完成配对
- 移动端发送的消息出现在桌面 Lily 对话中

---

### 阶段 2：屏幕观察
**目标**：移动端可以查看桌面屏幕

**交付物**：
- 桌面端屏幕捕获服务
- WebRTC 信令服务
- 移动端视频观看器

**验证标准**：
- 移动端可以看到桌面屏幕实时画面

---

### 阶段 3：语音输入
**目标**：移动端可以使用语音输入消息

**交付物**：
- 阿里云 Dashscope ASR 集成
- 移动端语音录制组件
- 语音转文本功能

**验证标准**：
- 移动端可以录音并转换为文本发送

---

### 阶段 4：控制输入
**目标**：移动端可以控制桌面鼠标键盘

**交付物**：
- Windows 输入注入 Helper
- macOS 输入注入 Helper
- 移动端控制界面

**验证标准**：
- 移动端可以移动桌面鼠标
- 移动端可以点击桌面
- 移动端可以输入文本

---

### 阶段 5：文件上传
**目标**：移动端可以上传文件到桌面 Agent

**交付物**：
- 分片上传 API
- 桌面端文件暂存
- Agent 附件集成

**验证标准**：
- 移动端上传的文件可以作为附件发送给 Agent

---
