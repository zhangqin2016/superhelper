## 行为

- 企业入口展开显示成员，支持昵称/Lily ID 搜索、仅看在线、在线优先和分批显示；点击同事创建企业内私聊，无需好友关系。个人好友保持独立。
- 新签名接口 `/api/collaboration/v1/enterprise-directory` 按当前账号的有效企业成员关系读取。已停用企业、已移除成员和企业外目录不可见；返回字段不包含手机号或登录凭据。
- 客户端在协作界面可见时每 15 秒刷新。临时网络错误使用上次目录并显示状态未知；已确认的成员移除不会被旧缓存恢复。
- 昵称写入账号及协作资料；缺失资料会创建随机公开 Lily ID，已有 Lily ID 保持不变。成员目录可使用账号显示名称兜底，不泄露登录名。
- 在线依据真实 WebSocket 连接、有效账户设备会话及心跳。多设备任一在线即在线；正常断开后下次目录刷新变为离线；心跳 75 秒未更新失效。缺少实时服务或离线缓存显示未知，不伪造在线。
- 当前生产为单 API 实例，连接状态保存在实例内存。若以后部署多个 API 实例，需要先引入共享在线状态存储；此版本没有声称支持跨实例在线汇总。
