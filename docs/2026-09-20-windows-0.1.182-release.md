# Windows 0.1.182 release

## Scope

Windows x64 only. OpenCode stays at 1.18.30. No macOS/GPU/server configuration,
model downgrade, context reduction or catalog publication.

Structured runner failures preserve native causes and execution progress. The
existing parent-closure owner resumes interrupted tool work, including after
SQLite reopen, without competing replay. Explicit non-retryable terminal errors
remain stopped. Acceptance-gap auto-repair stays opt-in.

## Real desktop acceptance

Current source Electron, actual Windows UI through native input, real configured
model, isolated 2GiB history profile. Session:
`73ef88fe-ff76-43e3-9d56-47ee0bcbdd88`.

- Report generation completed in 60s / 13 steps. Produced a Chinese Markdown
  report (2866 bytes) and CSV (377 bytes), with four stores and totals. Direct
  CSV readback confirms net sales 520000 and gross profit 201000. Final Markdown
  formatting, artifact cards and idle state displayed correctly.
- Started another read-only analysis and clicked Stop. UI became interrupted
  and idle, without automatic restart. Explicit subsequent continue completed
  in 8s, preserving the narrowed scope and correct totals.
- Killed only the positively identified child engine of the isolated test app
  during tool work. The app automatically resumed and completed in 31s, without
  a Retry click. This exposed Windows exit code 4294967295 being misclassified
  as HTTP 429. Added typed EngineExitError handling and a regression test.
- Restarted with the correction, repeated the actual engine interruption during
  work. UI correctly displayed engine unavailability, automatically continued,
  completed in 57s and returned idle. No manual retry or extra user message.

Logs are `release182-ui*` under the existing isolated temporary profile.
This is process-failure recovery, not a physical network-disconnect test. These
minute-scale runs do not certify hours-long tasks or every provider/skill.
Independent content verification still discloses its unverified status; actual
generated numbers were checked separately. No customer data was deleted.
