# UI 视觉全面翻新设计 — 日光极简

日期:2026-07-22
状态:已获用户确认(头脑风暴 + 可视化伴侣三轮选择)

## 背景与目标

Lily 工作台当前为深色默认主题(近黑中性色 + 紫罗兰 #6366f1)。用户要求"焕然一新"的全面视觉翻新。经三轮可视化选择确定:

- **风格方向**:日光极简(Notion/Linear 式浅色,靠留白、发丝线、细腻阴影分层)
- **主题策略**:浅色为主打,深色按同一设计语言配套重做;主题模式逻辑(system/dark/light,默认跟随系统)不变
- **点缀色**:保留品牌紫罗兰 #6366f1,浅色版变柔和
- **实施范围**:方案二 — 令牌层翻新 + 聊天主界面(消息流/输入区/顶栏)骨架微调;设置页、PDF 查看器等次要界面只做令牌对齐,不动骨架

## ① 设计令牌层(`src/renderer/styles/base.css`)

### 浅色主题(主打)

- 背景阶梯:暖灰 `--bg-body #f7f7f5` → 侧栏 `#fbfbfa` → 表面纯白 `#ffffff`
- 边框:发丝线 `#e8e8e4` 系(按现有 border/border-light/border-subtle 层级映射)
- 文字三级:`#1f2328`(主)/ `#6b6b66`(次)/ `#a3a39d`(弱)
- 点缀紫:`--accent #6366f1`,浅紫底 `#f3f1ff`(选中态),淡紫边(工具卡)
- 成功绿 `#2f9e6e`(工具完成勾等状态色沿用语义令牌)
- 阴影阶梯三级:rest(0 1px 2px)/ raised(0 4px 16px,带紫调)/ floating(浮层)

### 深色主题(配套重做)

- 暖调深灰阶梯(非纯黑),与浅色一一对应的层级关系
- 同一紫罗兰提亮版(暗底上的可感知度与浅色版一致)
- 与浅色共享圆角、阴影、间距刻度

### 共享尺度

- 圆角层级:6px(小件/chip)/ 10px(卡片)/ 14px(输入区、气泡)
- 间距刻度沿用现有密度,不整体加疏(避免信息密度退化)

## ② 组件样式扫除(17 个 CSS 文件)

`src/renderer/styles/` 下全部样式文件逐文件处理:

- 硬编码颜色值收编到语义令牌(白名单:transparent、currentColor、品牌渐变所用的固定色值)
- 圆角、阴影、间距统一到 ① 的尺度
- **只换值,不改选择器结构**,保证 diff 可逐行审查
