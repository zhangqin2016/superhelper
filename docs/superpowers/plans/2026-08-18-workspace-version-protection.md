# 工作区版本保护实施计划

## 目标

实现隐藏 Git 版本引擎、降级快照、任务自动保护和普通用户可用的版本历史面板。

## 步骤

1. 建立版本策略、Git 适配器、快照降级和版本服务。
   - 新增 `src/main/workspace-version-policy.js`
   - 新增 `src/main/workspace-git.js`
   - 新增 `src/main/workspace-snapshot-store.js`
   - 新增 `src/main/workspace-version-service.js`
2. 接入主进程上下文、项目 IPC 和 preload。
   - 初始化服务但不阻塞启动
   - 增加状态、历史、保存、恢复 IPC
3. 接入任务生命周期。
   - 任务开始记录安全基线
   - 成功归档后异步自动保存
   - 任何版本失败只记录日志，不阻断原有归档
4. 增加项目菜单中的版本保护面板。
   - 展示 Git/本地保护状态和未保护修改
   - 提供保存、历史和恢复确认
5. 增加测试并验证。
   - Git 适配器和安全策略
   - 服务保存/恢复/基线隔离
   - IPC 契约和 renderer 静态检查

## 约束

- 不触碰用户已有 `.git`。
- 不删除或重置用户文件。
- 不改动角色、世界书或法律知识库逻辑。
- 不提交与本功能无关的现有工作区修改。
